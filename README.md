# Employee Management System (C++ OOP)

## 📌 Project Description

This is a simple **Object-Oriented Programming (OOP)** project written in **C++**.
The program demonstrates how to use classes and member functions to store and display employee information.

The system allows saving employee data such as:

* Employee ID
* Employee Name
* Employee Salary

and then printing this information to the console.

---

## 🧠 Concepts Used

This project demonstrates the following C++ concepts:

* Classes and Objects
* Member Functions
* Variables inside Classes
* Basic Input and Output
* Object-Oriented Programming (OOP)

---

## 🧾 Code Example

```cpp
company employee_Info;

employee_Info.save(2582007, "yazan abushreefih", 11.5);
employee_Info.print();
```

---

## ▶️ How to Run the Program

1. Install a C++ compiler (such as **g++**).
2. Compile the program:

```
g++ main.cpp -o program
```

3. Run the program:

```
./program
```

## 🎯 Project Goal

The goal of this project is to practice **Object-Oriented Programming in C++** and understand how classes can be used to organize and manage data.
